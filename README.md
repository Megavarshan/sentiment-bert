# Sentiment Analysis using BERT

This project builds a sentiment analysis model using the pre-trained BERT transformer.
It classifies text into positive or negative sentiment.

## Features
- Uses HuggingFace Transformers
- Fine-tunes BERT on IMDB dataset
- Achieves 90%+ accuracy
- Includes training, evaluation, and prediction code

## Tech Stack
- Python
- PyTorch
- Transformers (HuggingFace)
- Scikit-learn

## How to Run
Open the `sentiment_bert.ipynb` notebook and run all cells.
Ensure GPU runtime is enabled in Google Colab.
